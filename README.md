# 网络访问稳定性指南

一个以“先判断问题，再测试原因”为核心的信息站。内容围绕视频加载/缓冲、游戏延迟/丢包、晚高峰、远程办公、公共 Wi-Fi，以及网络工具的选择与测试。

## 内容原则

- 每个页面只围绕一个主要用户任务。
- 优先给出可复现的对照测试，而不是堆“常见原因”。
- 网络原理和平台指标优先引用官方或可靠专业来源。
- 产品资料区分公开事实、产品方声明和第一手材料。
- 没有第一手数据时，不写实测速度、延迟、错误码、价格或效果结论。
- 只有在存在独立用户任务时才新增页面，避免内容职责重复。
